# 定期購買サービス 解約要因調査

## 調査概要
2025年10月〜2026年3月の解約者を対象に、購買ログとアンケートを分析した（n=1,284）。
アンケート回答者は412名（n=412）。

## 定量結果:解約タイミング
初月への集中が顕著である（n=1,284）。

| 経過月 | 解約者数 | 構成比 |

| 1ヶ月目 | 745 | 58% |
| 2ヶ月目 | 244 | 19% |
| 3ヶ月目 | 141 | 11% |
| 4ヶ月目以降 | 154 | 12% |

## 定量結果:解約理由のラベル集計

| 配送日が合わない | 140 | 34% |
| 量が多すぎる | 115 | 28% |

## 定性結果:機能認知の不足
> 配送日が変えられると知らなかった。気づいたときには2回目が届いていた
-- 30代女性・3ヶ月で解約

> 量を減らせるなら続けたかったが、問い合わせ方法が分からなかった
-- 40代女性・2ヶ月で解約

機能の認知不足に言及した回答は128件（31%）だった。

## 提言
初月の体験設計に絞って改善する。初回配送前の案内、少量プランの提示、
2週間以内のヒアリングを既存の通知基盤で実装する。
