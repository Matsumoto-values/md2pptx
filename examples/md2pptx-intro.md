# md2pptx とは
Markdown から編集可能な PowerPoint を自動生成する仕組みです。
- HTML/CSS をレイアウトエンジンとして使う
- 表・グラフ・図形はネイティブ要素として生成する
- 会社テンプレートのデザインをそのまま適用できる
!! 生成された資料は PowerPoint で自由に編集できます
---
# 従来のやり方の課題
資料作成の工数は、内容を考える時間より整形に費やされがちです。
- 同じ構成の資料を顧客ごとに作り直している
- 数値が更新されるたびに手作業で差し替えている
- テキストが枠から溢れても、開くまで気づけない
---
# 仕組み
```flow
Markdown: 内容だけを書く
HTML: ブラウザが折り返しと座標を計算
PowerPoint: 座標どおりに配置する
```
レイアウトの判断はすべてブラウザに任せ、生成側は配置に徹します。
---
# 従来手法との比較
| 観点 | 手作業 | 本システム |
| --- | --- | --- |
| 1資料あたりの作成時間 | 120 | 8 |
| 文字あふれの検知 | 0 | 100 |
| 顧客ごとの展開コスト | 100 | 5 |
数値は相対値です。整形作業がほぼ不要になります。
---
# 作成時間の削減効果
```chart
type: column
categories: [提案書, 定例報告, 事例紹介, 社内共有]
series:
  - {name: 手作業, values: [120, 90, 75, 60]}
  - {name: 本システム, values: [8, 5, 6, 4]}
```
単位は分。テンプレート登録後は内容を書くだけで完成します。
---
# 生成実績の推移
```chart
type: line
categories: [4月, 5月, 6月, 7月, 8月]
series:
  - {name: 生成資料数, values: [12, 34, 68, 121, 180]}
```
夜間バッチで顧客ごとの資料をまとめて生成しています。
---
# 導入の流れ
```flow
STEP1: 既存資料を登録
STEP2: プレビューで確認
STEP3: Markdown から生成
```
テンプレートは一度登録すれば、以後は内容を書くだけで同じデザインの資料が出ます。
