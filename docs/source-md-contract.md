# 調査報告書 md の構造規約

md2pptx でスライド化する調査報告書（インタビュー・ラベル集計）を md で書くときの規約。
**レポート作成担当者向け。**

## この規約の考え方

**報告書をスライド向けの形式にはしない。** 報告書とスライドは目的が違う。

| | 調査報告書 | スライド |
|---|---|---|
| 目的 | 証跡・追跡可能性 | 説得・持ち帰り |
| 逐語引用 | すべて載せる | 代表的な1〜2件 |
| ラベル集計 | 全カテゴリ | 上位5件＋その他 |
| 網羅性 | 高いほどよい | **捨てることが価値** |

「捨てる判断」はスライドを作る時点で行う。報告書側で先に捨ててしまうと、
報告書としての価値が落ちるうえ、別の切り口でスライドを作り直せなくなる。

**この規約で求めるのは見た目ではなく構造だけ。**
分量・見出しの言い回し・要素の選び方は自由に書いてよい。

---

## 1. 数値には必ず母数を書く

固定表記 `n=数値` を使う。カンマは入れても入れなくてよい。

```markdown
アンケート回答は412名（n=412）。
```

- **理由**: スライド側は母数の記載がないグラフ・表に警告を出す。定性データは
  母数が小さいことが多く、n のない構成比は誤読を招く
- セクション全体で母数が共通なら、セクション冒頭に1度書けばよい

## 2. ラベル集計は表で書き、列を固定する

```markdown
| ラベル | 件数 | 構成比 |
| --- | --- | --- |
| 配送日が合わない | 140 | 34% |
| 量が多すぎる | 115 | 28% |
| 価格が高い | 86 | 21% |
```

- 列は **ラベル / 件数 / 構成比** の順。名前は揃える
- **全カテゴリを載せる**（丸めるのはスライド側の仕事）
- 構成比は `%` を付ける。件数は付けない
- 集計軸が複数あるなら表を分け、直前の見出しに軸を書く

## 3. 逐語引用は `>` と `--` で書く

```markdown
> 配送日が変えられると知らなかった。気づいたときには2回目が届いていた
-- 30代女性・3ヶ月で解約
```

- `>` の行が発言、**直後の行**を `--` で始めて話者の属性を書く
- **属性は必須**。無いと読み手が代表性を判断できない
- 属性の書式は「年代・性別・状態」を推奨（例: `40代男性・継続12ヶ月`）
- **逐語のまま書く。** 要約・整形・語尾の調整をしない。長い場合は
  前後を落として切り出す（言い回しは変えない）
- 発言が2文以上に渡る場合も1行にまとめる（改行を入れない）

この記法はスライド側でそのまま引用要素になる。**変換作業が不要。**

## 4. セクションに役割を書く

見出しに役割を示す語を含める。スライド側が材料を探すときの手がかりになる。

| 役割 | 見出しの例 |
|---|---|
| 調査概要 | `## 調査概要` / `## 調査設計` |
| 定量結果 | `## 定量結果:解約タイミング` |
| 定性結果 | `## 定性結果:解約理由の語り` |
| 比較 | `## 比較:継続会員との差分` |
| 示唆 | `## 示唆` / `## 考察` |
| 提言 | `## 提言` / `## 施策の方向性` |

- `## 定量結果:〜` のように **役割 + コロン + 内容** が最も扱いやすい
- 見出しの階層は `##` までを推奨（`###` 以下は無視される想定で書く）

## 5. 時系列・推移は表で書く

グラフにしたい数値は表で渡す。**文中に埋め込まない。**

```markdown
| 月 | 解約者数 |
| --- | --- |
| 4月 | 12 |
| 5月 | 34 |
```

- 悪い例: 「4月は12名、5月は34名、6月は68名だった」
  → スライド側が数値を拾えず、グラフにできない（あるいは転記ミスが起きる）
- 表にしておけば `chart` に変換できる

## 6. 書いてよいこと・避けること

**書いてよい（スライド側が処理する）**
- 長い散文、詳細な方法論、全カテゴリの集計、引用の全件、脚注、参考資料

**避ける**
- 数値を文中にだけ書く（→ 表にする）
- 引用を要約する（→ 逐語で書く）
- 引用に属性を付けない
- `n` を書かない
- 表の列数を行ごとに変える（スライド側でエラーになる）

---

## スライド化を依頼するとき

報告書 md を渡して「これをスライドにして」と頼めばよい。
Claude 側は `.claude/skills/md2pptx-deck-authoring` に従い、
構成を組み立てて `tools/lint_md.py` で検証する。

テンプレート（配色・ロゴ）を指定する場合はテーマIDを伝える。
一覧は `ls themes/*.json`。
